Project Overview:

This project demonstrates the complete Business Intelligence lifecycle by transforming raw AdventureWorks sales data into an enterprise-style SQL Server Data Warehouse and 
developing an interactive Power BI dashboard for business reporting.

The project includes:

Data Extraction
Data Cleaning
ETL Development
Star Schema Design
SQL Reporting Views
Power BI Data Modeling
DAX Calculations
Interactive Dashboard Development

Objective

To build a scalable Business Intelligence solution that enables stakeholders to analyse sales performance, customer behaviour, product performance and product returns 
using interactive visualisations.
